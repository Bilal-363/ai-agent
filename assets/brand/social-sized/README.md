folder and never touches `../social/`, `../lockup/` or `../logo-compact/`.

## About the orange

```
#FF6A00   the "Ai" on white
#FF9A3D   the "Ai" on the gradient — lighter, so it holds up against violet
```

The gradient panel here runs **blue to violet only**, with no orange in it. The
earlier version ran blue-violet-orange and landed its orange corner exactly where
the wordmark sits, so an orange "Ai" would have disappeared into the background.
Keeping the orange out of the panel is what lets the type own it.

Wordmark is Plus Jakarta Sans ExtraBold, scaled so its width matches the mark's.
