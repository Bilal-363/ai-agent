# Vocryn Ai — brand kit

Generated by `node build/brand.js`. Everything here derives from one source file,
`build/logo-src/mark-hi.png`, so replacing that and re-running regenerates the whole
kit consistently. Don't hand-edit these PNGs — change the source and rebuild.

---

## Lockups (`lockup/`)

| File | Use |
|---|---|
| `lockup-stacked-*.png` | 1600×1200. Mark above, **VOCRYN Ai** beneath, tagline under that. The primary lockup. |
| `lockup-horizontal-*.png` | 2000×620. Mark beside the wordmark. Use where height is tight — email signatures, letterheads, site headers. |
| `mark-only-*.png` | 1200×1200. The ribbon alone, no words. |

Four themes each:

- **`-light`** — for white and pale backgrounds
- **`-dark`** — for deep navy backgrounds
- **`-brand`** — on the blue→violet→orange gradient
- **`-transparent`** — no background at all. **This is the one to send anyone who asks for "your logo".**

## Profile pictures (`social/profile-*`)

Sized per platform, `-light` (white) and `-brand` (gradient) of each.

| File | Platform |
|---|---|
| `profile-1024-*` | Master — upload this anywhere that accepts a large file |
| `profile-800-youtube-*` | YouTube channel icon |
| `profile-500-facebook-*` | Facebook page |
| `profile-500-whatsapp-*` | WhatsApp Business |
| `profile-400-x-*` | X (Twitter) |
| `profile-320-instagram-*` | Instagram |
| `profile-300-linkedin-*` | LinkedIn company logo |
| `profile-200-tiktok-*` | TikTok |

**These are circle-crop safe.** Every platform above masks avatars to a circle;
the wordmark is kept inside the inscribed circle so nothing clips. Verified.

> **One honest caveat.** At the size an avatar is *actually displayed* — roughly
> 32–48px in a feed — "VOCRYN Ai" is too small to read on any of these. It reads
> as texture. If you want the avatar to work at feed size, use `mark-only-brand.png`
> instead and let the ribbon do the work; the handle next to it already says the
> name. The lockup versions are the right choice for the profile *page*, where the
> avatar renders large.

The lockup is centred in every cover, which is deliberate: each platform crops
banners differently on mobile versus desktop, and centre is the only region all
of them keep. YouTube in particular shows only a 1546×423 strip on TV and mobile.

## Colours

```
Ink        #0B1030    wordmark on light
White      #FFFFFF    wordmark on dark and gradient
Accent     #B24C04    the "Ai", on light
Accent alt #FF9D5C    the "Ai", on dark
Gradient   #3A49CE → #7C3AED → #FF8125
```

Typeface: **Plus Jakarta Sans ExtraBold (800)** for the wordmark, letter-spaced
`-0.02em`. Tagline is the same face at 700 with `0.16em` tracking, uppercase.

## Regenerating

```bash
node build/brand.js
```

Add or change sizes in the `SQUARES`, `APP_ICONS` and `COVERS` arrays at the top
of that file. Fonts load from Google Fonts at render time, so the machine running
it needs a network connection — otherwise the wordmark silently falls back to a
system face, which is the one failure mode worth watching for.
